# FitLife
Atividade:
"A academia local FitLife está modernizando seu atendimento para atrair o público jovem. A direção contratou a sua equipe de desenvolvedores front-end para criar o site oficial do estabelecimento.
O maior objetivo da academia é captar novos alunos online. Para isso, além de uma apresentação visual atraente, o site precisa conter um formulário de pré-matrícula funcional que envie os dados diretamente para o e-mail da recepção sem a necessidade de configurar um servidor próprio."
